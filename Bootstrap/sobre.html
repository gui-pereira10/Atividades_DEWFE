Sobre o Projeto

Este site foi desenvolvido exclusivamente para fins educacionais, com o objetivo de praticar conceitos de HTML, CSS, Bootstrap e responsividade durante os estudos de desenvolvimento web.

Todos os produtos, imagens e referências utilizadas possuem caráter ilustrativo e não representam uma loja oficial ou comercialização real.

O projeto busca demonstrar a criação de layouts responsivos, utilização de componentes do Bootstrap e organização de páginas web.
